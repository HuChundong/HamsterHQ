# 工作区工具与预览

[English](artifact-panel.md)

`packages/dsh-artifact-panel` 向 DSH 右侧栏提供内容。框架、导航、标签栏、调整宽度和上下文生命周期由 DSH 管理。部署提供增强的文件和画布；浏览器与终端由 DSH 提供。左侧云端电脑入口打开会话旁的右侧标签；定时任务另外保留全局页面。

## 导航与归属

每种内容通过 `ctx.sidebarRightTabs` 注册类型，并以相同类型标识填入 `sidebar.right.pane.tab`。引导页提供工作区工具和电脑。部署不再维护 body 层面板、会话列的外边距或另一套标签状态。

会话顶部保留部署原有的单行设计：标题、对话／轨迹切换、右侧操作。CSS 通过公开的标题栏插槽和语义子节点定位，不搬动 DOM，也不替换上游控件。所有规则共用结构条件，上游结构变化时一起回退；层叠层保留空白会话隐藏标题栏的行为。`verify/verify-sidebar.mjs` 检查对齐、窄屏和切换。

DSH 负责上下文选择、资源导航和标签关闭。组件通过 `useTabInfo` 读取当前标签；文件树使用官方工作区文件地址辅助函数，调用 `tab.actions.openResource`。打开文件与上游路径链接和产物列表因此使用相同导航。插件不再替换 `remote.session.openWorkspacePath`。

云端电脑和定时任务在沙箱状态上方注册底部入口。电脑对应的 main 标识仅表示导航请求：根控制器返回会话，等会话界面挂载后打开右侧标签。没有选中会话时等待会话选择。定时任务保留 main 页面。账户菜单替换底部的 `settings.trigger`，设置收进账户菜单，沙箱状态仍留在底部，点击后打开设置中的沙箱配置。上游设置弹窗状态未公开，因此一处适配器拦截该按钮的点击来打开账户菜单，在选择菜单中的设置或点击沙箱快捷入口时放行原按钮点击。快捷入口在弹窗挂载后通过固定标识选中沙箱配置页。常驻的账户组件继续为沙箱设置页提供环境变量与重启控件。

## 文件与预览

文件工具自己管理目录树和预览器，通过网关基于 envd 的文件路由读取数据。每个文件在 DSH 资源标签中同时显示预览和可折叠目录树。文本和图片通过 `/sandbox/raw/*` 读取，HTML 使用既有带票据的预览通道，让相对资源可以正常加载。PDF 使用浏览器内嵌查看器；不支持的二进制文件提供下载。Markdown 保留源码／预览切换。

插件以扩展优先级接管标准会话文件地址。因此主会话的文件链接和产物操作通过 DSH 公开资源导航打开同一个自有文件界面，不替换 Remote 方法。外层标签、宽度调整和会话选择仍由官方框架管理。

面包屑定位目录，目录树高亮当前文件，复制操作读取经过鉴权的完整文件。工作区监听器直接刷新自有预览和目录树。删除文件时通过标签自身的操作关闭对应资源标签，不再通过 DOM 激活其他预览器的刷新按钮。

文件树使用经过认证的网关文件路由。网关通过官方客户端访问 envd，并采用 CubeProxy 的路径路由。artifact 插件保留空的 host 入口，让模块注册表加载其浏览器半边；它不在沙箱内新增文件 RPC 服务。

网关文件路由接受调用者沙箱内的任意绝对路径。`/mnt/workspace` 是文件树的浏览根目录，不是从其他入口打开文件链接时的 API 路径限制。租户隔离来自调用者认证与对应沙箱的解析。符号链接不是额外的租户边界。部署和模型平面见[设计说明](design.zh.md)。

## 终端生命周期

终端渲染器、PTY 和会话生命周期由 DSH 管理。内置终端通过网关隧道承载的鉴权 DSH API 和 remote mux 通信。重新连接可以恢复运行中的进程与屏幕；关闭终端标签会结束进程。终端归属于当前 DSH 会话。

artifact 插件不再注册终端类型或维护独立渲染器。网关基于 envd 的独立终端仍保留在恢复页，以便 DSH 无法启动时修复沙箱。

## 画布与浏览器

画布继续使用带票据的 HTML 表面，与上游文档预览分开。它通过工作区监听器跟随最新 HTML 页面，并在相关文件变化时刷新。打开画布表达用户希望跟随产物的意图；生成文件不会自动打开其他标签。

预览使用路径编码 URL，让相对资源在文档旁正确解析。iframe 与响应 CSP 均不授予 `allow-same-origin`，使文档处于不透明源。短期票据授权预览，不向沙箱页面交出租户的普通会话凭据。票据过期和响应头以网关预览路由为准。

普通网页标签由 DSH 内置浏览器管理。它在用户浏览器内显示 iframe，不共享沙箱 Chromium 会话。artifact 插件不再注册浏览器或轮询截图；观察与接管沙箱浏览器由云端电脑负责。

## 云端电脑与人工接管

`dsh-computer` 在官方右侧栏渲染桌面，从左侧云端电脑入口打开时也使用同一标签。右侧桌面作为预览：悬浮或键盘聚焦显示“打开”，点击整个区域会在新窗口打开 noVNC。下方通过声明的 `computer.schedule` 插槽显示紧凑任务列表，标题旁使用加号入口。点击任务在侧栏内进入二级详情页，底下的电脑 frame 保持挂载且尺寸不变，返回后恢复列表。独立定时任务页使用相同的列表和详情控件。紧凑编辑页将返回、启用、删除和保存放在固定工具栏，只有字段区域滚动。按钮和开关使用官方 UI 组件；操作失败时保留编辑页和当前状态，允许重试。两个左侧底部入口均可切换打开和关闭。全屏时隐藏任务和新窗口遮罩，同一个 noVNC frame 直接接收操作；退出全屏后恢复预览模式。定时任务也保留全局管理页面。

人工操作卡片和全窗口接管仍由 `dsh-computer` 负责。`computer_request_user_action` 使用 DSH 公开的用户问题流程完成或跳过；打开接管本身不会结束等待。其 `DesktopFrame` 跟随 noVNC 的就绪、错误与重连状态。同一个 noVNC 页面也可在新窗口打开。

## 验证与包边界

`scripts/check-computer-layout.mjs` 检查部署的导航契约；`scripts/check-computer-loading.mjs` 覆盖 noVNC 就绪状态与启动逻辑。`scripts/check-icons.mjs` 保证无构建客户端的内联字形与生成源一致。树检查不能证明新 harness 的运行时兼容性：必须按 [AGENTS.md](../AGENTS.zh.md) 重建镜像、运行镜像检查，并在可丢弃的部署上完成验收套件。

artifact 包打包额外运行时依赖，React 则来自 DSH 模块表。其他直接提供源码的浏览器插件不能导入兄弟包。内容使用 shell 主题令牌与 `ctx.locale`；布局和上下文状态留给 DSH。
